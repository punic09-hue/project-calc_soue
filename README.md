# Калькулятор зоны оповещения СОУЭ (СП 3.13130.2026)

Открыть: `https://<логин>.github.io/<репозиторий>/`

Включение сайта: Settings → Pages → Source: Deploy from a branch → `main`, папка `/ (root)`.

## Базы оповещателей
Лежат в папке `db/` (CSV, разделитель «;», UTF-8). Список для меню «База с сайта» — `db/index.json`.
Добавить базу: положить CSV в `db/` и дописать строку в `index.json`:
`{"file":"Имя.csv","title":"Подпись в меню"}`.
Заголовки столбцов — как в существующих базах.

При открытии `index.html` с диска меню не появится (браузер не даёт читать файлы рядом) — тогда кнопка «Загрузить базу из CSV».
